# PM-2024-11: Booking outage caused by retry storm against Northline rate limits

## Summary

For 47 minutes (14:02–14:49 UTC) shippers could not create bookings or print labels for any carrier. The shared carrier client exhausted its connection pool while retrying calls to Northline Carriers, which was rejecting our traffic with HTTP 429.

## Timeline (UTC)

- 13:55 Northline deploys a change that enforces its 100 requests/second limit per account instead of per API key.
- 14:02 Northline starts returning 429 Too Many Requests on roughly 90% of our calls.
- 14:03 Our carrier client retries each failed call up to 5 times with exponential backoff and no jitter. Traffic to Northline climbs from 60 to about 280 requests/second.
- 14:06 Connection pool in `carrier-client` saturates; calls to BlueRidge and Pacific Coast queue behind Northline retries.
- 14:31 Retries disabled via config push; pool drains.
- 14:49 Bookings fully recovered.

```
2024-11-18T14:03:12Z WARN carrier-client northline POST /v2/labels status=429 attempt=3/6 backoff=800ms
2024-11-18T14:05:47Z ERROR carrier-client pool exhausted active=512 waiting=4381 carrier=northline
2024-11-18T14:06:02Z ERROR booking-api label generation failed carrier=blueridge err="context deadline exceeded"
```

## Root cause

The retry policy assumed carrier failures are transient and independent. These failures were throttling responses: every retry added load to a carrier that was already rejecting us, so failures were correlated and retries amplified them. With about 90% of attempts failing, each request made on average about 4.7 attempts, pushing us to 2.8 times Northline's limit. The "generous" 100 requests/second headroom disappeared as soon as retries multiplied traffic.

## Impact

- 47 minutes without bookings; about 3,900 booking attempts failed.
- 212 support tickets; two enterprise shippers requested service credits.

## Lessons and action items

1. Never retry 429 responses without honouring Retry-After; add jitter.
2. Add a per-carrier circuit breaker and a retry budget (max 10% extra traffic).
3. Isolate connection pools per carrier.
4. Revisit ADR-027: retries must be conditional on the failure type.
